# AI Software Engineer Agent - API Quick Reference

## Base URL
```
http://localhost:5000/api
```

## Quick Start Example

### 1. Create a Session
```bash
curl -X POST http://localhost:5000/api/session/create \
  -H "Content-Type: application/json" \
  -d '{}'
```

### 2. Execute a Task
```bash
curl -X POST http://localhost:5000/api/task/execute \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Create a simple Express.js REST API with user CRUD endpoints",
    "language": "javascript",
    "framework": "express",
    "execute_code": false,
    "auto_debug": true
  }'
```

### 3. Get Task Status
```bash
curl http://localhost:5000/api/task/status/task_abc123
```

## Common Use Cases

### Generate a React Component
```json
POST /api/task/execute
{
  "prompt": "Create a reusable Button component in React with TypeScript",
  "language": "typescript",
  "framework": "react"
}
```

### Build a Python REST API
```json
POST /api/task/execute
{
  "prompt": "Build a FastAPI app with authentication and CRUD for products",
  "language": "python",
  "framework": "fastapi"
}
```

### Create Tests
```json
POST /api/task/execute
{
  "prompt": "Generate unit tests for a Todo list class in JavaScript",
  "language": "javascript"
}
```

### Execute Code
```json
POST /api/code/execute
{
  "code": "def factorial(n):\n    return 1 if n <= 1 else n * factorial(n-1)\nprint(factorial(5))",
  "language": "python",
  "timeout": 30
}
```

### Push to GitHub
```json
POST /api/github/action
{
  "action": "create_repo",
  "repo_name": "my-ai-project",
  "description": "Generated by AI Dev Agent"
}
```

Then push code:
```json
POST /api/github/action
{
  "action": "push_code",
  "repo_name": "my-ai-project",
  "files": {
    "index.js": "console.log('Hello');",
    "package.json": "{\"name\": \"my-app\"}"
  }
}
```

### Search Memory
```json
POST /api/memory/search
{
  "query": "React components with hooks",
  "limit": 5
}
```

## WebSocket Support (Coming Soon)
Real-time updates during task execution:
```javascript
const ws = new WebSocket('ws://localhost:5000/ws/task/task_id');
ws.onmessage = (event) => {
  const update = JSON.parse(event.data);
  console.log(`Phase: ${update.phase}, Progress: ${update.progress}%`);
};
```
