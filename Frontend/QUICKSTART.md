# Quick Start Guide for AI Dev Agent Frontend

## Installation Steps

1. Open terminal in the Frontend directory
2. Install dependencies:
   ```
   npm install
   ```

3. Start development server:
   ```
   npm run dev
   ```

4. Open your browser to: http://localhost:3000
